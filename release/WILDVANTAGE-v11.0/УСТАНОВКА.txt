УСТАНОВКА НА ANDROID
====================

1. Скачай файл «WILDVANTAGE-v11.0-SmartIcons.apk» на телефон.
2. Открой его (проводник / загрузки) и разреши установку:
   «Настройки → Безопасность → Устанавливать из неизвестных источников».
3. Дождись установки и нажми «Открыть».
4. При первом запуске разреши доступ к местоположению (для GPS).

Онлайн-погода работает сразу (ключ уже внутри приложения).
Режим «Глушь» (переключатель в приложении) работает полностью без интернета.

Требования: Android 7.0 и выше.
