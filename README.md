# 🎯 WildVantage

Приложение для Android, которое помогает на природе: погода на 5 дней, восход и закат, компас и твои координаты — даже там, где нет связи.

---

**Что умеет:**

- 🌤 **Погода на 5 дней** — по-русски, с ночными и дневными температурами (например: «22° / 12°»)
- 🌅 **Восход и закат** — точное время для твоего места, считается прямо на телефоне, интернет не нужен
- 🧭 **Компас** — показывает направление (С, СВ, В и т.д.)
- 📡 **GPS** — живые координаты одной кнопкой
- 🌲 **Режим «Глушь»** — полный офлайн: координаты, солнце и погода из кэша, без единого запроса в сеть
- 🔍 **Поиск города** — просто напиши «Москва» или «Ярославль»
- ⚡ **Всё быстро** — интерфейс не зависает, даже когда качаются данные

---

**Кому пригодится:**

- туристам и походникам — погода и свет в точке стоянки
- рыбакам и охотникам — утренний и вечерний клёв связаны со светом
- грибникам — не заблудиться в лесу по азимуту
- фотографам — поймать рассвет или закат в нужном месте
- дачникам и всем, кто просто хочет знать, когда стемнеет

---

**Как установить:**

1. Скачай `release/WILDVANTAGE-v11.0-SmartIcons.apk` (или `release/WILDVANTAGE-v11.0-SmartIcons.zip` — там же лежит инструкция).
2. Открой файл — разреши установку из неизвестных источников.
3. При первом запуске разреши доступ к местоположению.

*Онлайн-погода работает сразу после установки — ключ уже внутри приложения. У бесплатного ключа OpenWeatherMap есть лимит (~1000 запросов в день), его хватает с запасом. Режим «Глушь» работает вообще без интернета.*
