# 🌲 WildVantage

**WildVantage** — погодное приложение для Android для города и природы. Показывает текущую погоду, почасовой прогноз с 00:00 до 23:00, прогноз на неделю, восход и закат, координаты GPS и геомагнитный Kp-индекс NOAA. Работает офлайн по сохранённым данным и не теряет погоду при переключении между городами.

> **Текущая версия:** v13.1.0 — Beta. Она ещё не проверена на реальном телефоне, поэтому опубликована как pre-release. Если заметите ошибку — напишите в Issues.

---

## Что умеет приложение

- 🌤 **Погода сейчас** — температура, «ощущается как», влажность, ветер в м/с и км/ч, описание и иконка.
- 🕐 **Погода по часам** — весь текущий день места с 00:00 до 23:00. Прошедшие часы сохраняются, текущий час отмечен «Сейчас».
- 📅 **Прогноз на неделю** — минимум и максимум температуры, осадки и иконки по дням.
- 📍 **GPS-место** — отдельная карточка «Текущее местоположение», всегда первая в списке городов. Её нельзя удалить.
- 🏙 **Города** — поиск, сохранение и переключение между городами. У каждого города свои погода, время обновления, часы и прогноз.
- 🌅 **Восход и закат** — рассчитываются на телефоне по координатам, интернет не нужен.
- 🌌 **Геомагнитная активность** — реальный планетарный Kp-индекс NOAA SWPC.
- 📴 **Офлайн** — приложение показывает сохранённые данные, когда сети нет.
- 🔔 **Уведомления** — дождь, снег, гроза, сильный ветер, резкие скачки температуры и давления. Типы уведомлений настраиваются отдельно.
- 🌲 **Режим «Глушь»** — минимум сетевых запросов, данные из кэша.
- ⚙️ **Настройки** — шестерёнка в правом верхнем углу главного экрана.

## Что нового в v13.1.0

- **Независимый GPS-кэш.** Текущее место хранится в отдельном файле и восстанавливается после перезапуска, даже если вы выбрали город. Чужая погода больше не выдаётся за GPS-точку.
- **Защита от старой точки.** При существенном перемещении (примерно больше 11 км) старый снимок GPS сбрасывается, а не показывается как погода нового места.
- **История часов.** Прошедшие часы текущего дня сохраняются при обновлении и после перезапуска. После полуночи начинаются новые сутки — вчерашние часы не подмешиваются.
- **Независимые города.** Москва → Тверь → Москва, GPS → Тверь → GPS и быстрое переключение не смешивают данные. Поздний ответ старого запроса отбрасывается.
- **Часовой пояс места.** Часы и время обновления считаются по поясу города или GPS-точки, а не по поясу телефона.
- **NOAA Kp по актуальному времени.** Kp выбирается по самому свежему `time_tag`, а не по порядку строк в ответе. В пояснении указаны источник и время данных.
- **Фоновые уведомления.** Java-воркер WorkManager сам запрашивает MET Norway, читает настройки и отправляет уведомления через канал Android. Разрешение POST_NOTIFICATIONS запрашивается на Android 13+.
- **Экран настроек и управление городами.** Шестерёнка справа сверху, отдельные переключатели типов уведомлений, карточки городов без наложений, длинные названия сокращаются аккуратно.
- **Стабильная вёрстка.** Проверены размеры экранов, включая 572×1272 и 320×640.

## Установка на Android

1. Скачайте APK на телефон.
2. Откройте файл через уведомление о загрузке или через «Файлы».
3. Android спросит разрешение **«Установка из неизвестных источников»** — разрешите для браузера или файлового менеджера.
4. Нажмите **«Установить»**. Если раньше стояла другая версия WildVantage, она обновится с сохранением данных.
5. Откройте приложение.

> APK подписан тестовым debug-ключом. Для обычной установки это не важно. Если Android откажется обновлять старую сборку, удалите старую версию и установите заново — настройки и города при этом могут сброситься.

## Первый запуск: разрешения

### GPS

1. При первом запуске приложение запросит доступ к местоположению.
2. Выберите **«При использовании приложения»** и разрешите точное местоположение.
3. Если запрос случайно отклонён: **Настройки Android → Приложения → WildVantage → Разрешения → Местоположение → Разрешить**.
4. Без GPS приложение покажет сохранённые данные, а не выдуманную погоду.

### Уведомления

1. На Android 13+ приложение запросит разрешение на уведомления. Нажмите **«Разрешить»**.
2. Если запрос пропущен: **Настройки Android → Приложения → WildVantage → Уведомления → Разрешить**.
3. В самом приложении нажмите **шестерёнку** справа сверху и включите нужные типы: дождь, снег, гроза, ветер, давление, температура.
4. Не отключайте мастер-переключатель уведомлений.

## Если уведомления задерживаются

Android может ограничивать фоновую работу приложений. Интервал обновления **около 15 минут не гарантируется**: система вправе отложить задачу при экономии заряда или без сети. Это ограничение Android, а не ошибка приложения.

Чтобы уведомления приходили чаще:

1. **Настройки Android → Приложения → WildVantage → Батарея → Без ограничений** (на разных прошивках пункт называется «Не оптимизировать», «Разрешить фоновую активность»).
2. **Настройки Android → Приложения → WildVantage → Мобильные данные → Разрешить фоновую передачу данных**.
3. На Xiaomi/Redmi: **Безопасность → Разрешения → Автозапуск → WildVantage**, а также «Экономия батареи → Без ограничений».
4. На Huawei/Honor: **Батарея → Запуск приложений → WildVantage → Управлять вручную**, включить автозапуск, косвенный запуск и работу в фоне.
5. На Samsung: **Уход за устройством → Батарея → Ограничения фоновой работы → Приложения, которые никогда не спят → WildVantage**.
6. На OnePlus/Oppo/Realme: **Батарея → Оптимизация батареи → WildVantage → Не оптимизировать**.

После перезагрузки телефона WorkManager восстанавливает периодическую задачу автоматически, если приложение хотя бы раз было запущено и имеет разрешения.

## Управление городами

1. На главном экране нажмите **«Управление городами»**.
2. Введите название города в поиск и добавьте его.
3. Каждая карточка показывает текущую температуру, минимум/максимум и время обновления.
4. **GPS-карточка «Текущее местоположение» всегда стоит первой.** У неё нет корзины — удалить её нельзя.
5. Чтобы удалить город, нажмите корзину на его карточке. Удаление не влияет на GPS-карточку и на выбранную погоду, пока вы не переключитесь.
6. Чтобы открыть погоду города, коснитесь его карточки. Снимок показывается сразу, затем данные обновляются из MET Norway.
7. Чтобы вернуться к текущему месту, коснитесь GPS-карточки. Приложение возьмёт координаты именно GPS-точки, а не последнего выбранного города.

### Переключение между городами

- Москва → Тверь → Москва: у каждого города свои температура, часы и время обновления.
- GPS → Тверь → GPS: GPS-карточка возвращает погоду текущего места, а не Твери.
- Быстрое переключение и переключение во время запроса безопасны: ответ старого города отбрасывается.
- Офлайн: показывается снимок выбранного города; если для GPS-точки данных нет, приложение честно сообщает «Нет данных для этого места», а не показывает чужой город.

## Настройки

Шестерёнка находится **в правом верхнем углу** главного экрана.

В настройках:

- мастер-переключатель уведомлений;
- отдельные переключатели: дождь, снег, гроза, ветер, давление, температура;
- тихий режим (ночные часы);
- пояснения по разрешениям Android.

Настройки сохраняются в отдельный JSON-файл и читаются Java-воркером фоновых уведомлений.

## Почасовая погода: 00:00–23:00

- Лента показывает **текущие сутки места** — от 00:00 до 23:00 по часовому поясу города или GPS-точки.
- Прошедшие часы не исчезают при обновлении: приложение сохраняет историю текущего дня.
- Текущий час выделен подписью **«Сейчас»**.
- После полуночи начинаются новые сутки. Вчерашние часы не переносятся.
- Если данных на день нет, показывается честная заглушка **«Нет данных»**, а не выдуманный прогноз.
- У каждого города своя лента часов; при переключении данные не смешиваются.

## Геомагнитный Kp-индекс NOAA

В приложении есть отдельный раздел **«Геомагнитная активность»**.

- Данные берутся из открытого продукта **NOAA SWPC** `noaa-planetary-k-index.json`.
- **Kp** — это **планетарный** индекс геомагнитной активности Земли, а не локальный прогноз для вашего города и не медицинская оценка самочувствия.
- Значения: спокойное поле, активное, буря G1–G5. Порог бури — Kp ≥ 5.
- В пояснении указываются источник и время актуальной точки данных.
- Без интернета показывается **«н/д»** — приложение не выдумывает значение.
- Глобальный Kp не заменяет локальный прогноз погоды и не гарантирует влияние на самочувствие.

## Источники данных и приватность

- Погода и почасовой прогноз — **MET Norway** (Locationforecast 2.0).
- Название места — **OpenStreetMap Nominatim**.
- Геомагнитный Kp — **NOAA SWPC**.
- Координаты и сохранённые прогнозы хранятся **только на телефоне**.
- Приложение не требует аккаунта и не отправляет данные на собственный сервер.
